# Proyek UTS PSD: Klasifikasi Tutupan Lahan Jawa Timur

**Joni Kumar Meghwar**  
**NIM 240411100234**

Dokumentasi proyek berdasarkan digitasi lima kelas pada `EastJawa_Data.geojson` milik Joni. Alur mengikuti CRISP-DM: tujuan → data → ekstraksi Sentinel-2 → persiapan → k-NN → evaluasi → dashboard Streamlit.

Kode dan tampilan diadaptasi dari proyek UTS Muhammad Ainul Fuady/PSD yang disediakan sebagai referensi. Data dan hasil evaluasi proyek referensi tidak digunakan sebagai hasil Joni.

Model aktual masih menunggu ekstraksi menggunakan akun Copernicus. Panduan deployment menjelaskan cara menjalankan proyek dan menambahkan URL aplikasi setelah publikasi berhasil.
